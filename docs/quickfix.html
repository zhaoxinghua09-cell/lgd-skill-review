quickfix

Fix what a machine can fix. Prove the delta.

大多数审计报告读完还是不会改。这条命令只做「机械可判定」的那几件事，并且改完立刻复评， 把分数差贴出来——不接受「我们改好了」这种自述。

Run it

# 先看它想改什么（默认 dry-run，不写盘）
python scripts/quickfix.py <package-dir>

# 真改：补 LICENSE + 声明 license 字段 + 生成 AI-INDEX.json + 对齐已声明命令
python scripts/quickfix.py <package-dir> --apply

# 改完立刻复评，拿到前后分数差
python scripts/review.py <package-dir> --run --json

默认只动「机械可判定」项，语义改写一律不碰；单文件改动超过 30% 会被拒绝写入。

What it actually moves

缺陷它能做什么实测效果
无 LICENSE、无 license 字段补 MIT 许可文件 + 加 front-matter 字段licensing 2 → 3
无机器可读索引生成 AI-INDEX.json（含入口与命令）discoverability 4 → 7
文档声明的命令脚本不存在只报告，不代写——这需要人决定保持阻断，避免掩盖

真实案例：microsoft/azure-skills 的 azure-deploy 从 20 分，仅靠机械整改到 24 分； 再补 tests/golden、可跑 runner、llms.txt、tags 到 57 分——剩下的必须由人写内容，机器补不了。

Measures verifiability, not usefulness or popularity. Low score means evidence is missing, not that the skill is bad. Snapshot at a point in time; the sample is not random.
