audit

Score, blockers, fix order — from one command.

It never reads your README and trusts it. With --run it executes the package's own golden set, so 「我自己测过」和「它真的能跑」是两件事。

Run it

# 静态六维评分（不执行目标代码）
python scripts/review.py <package-dir> --json

# 加上实跑：执行包内黄金集，拿到最后 4 分
python scripts/review.py <package-dir> --run --json

# 只看某一维的整改（例如「声明与实现是否一致」）
python scripts/review.py <package-dir> --run --focus declared-consistency

零依赖、不联网、标准库即可跑。退出码 0 通过 / 1 有阻断 / 2 参数错误。

What you get

输出内容
逐维分数structure 20 · consistency 25 · reproducible 20 · hygiene 15 · discoverability 15 · licensing 5
阻断项每条带 file:line 证据，不给「建议优化一下」这种无法执行的结论
整改顺序按「先修能一次修好的」排，改完复评能直接看到分数差
机器可读--json 输出 {ok, data}，可直接进 CI

What it deliberately does not do

  • 不判断技能「好不好用」——它只判断「陌生人能否核验」
  • 不替代人工评审：分数高不等于内容正确
  • 不执行不可信代码，除非你显式加 --run
Measures verifiability, not usefulness or popularity. Low score means evidence is missing, not that the skill is bad. Snapshot at a point in time; the sample is not random.
